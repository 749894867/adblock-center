Bilibili 专项净化

主广告模块已集成 app2smile 的 Bilibili JSON 与 Protobuf 响应清理，覆盖开屏、推荐页、底部 Tab、视频详情与动态推荐；脚本每日同步并托管在本仓库。

必须完成一次 HTTPS 解密设置：在 PopCat 打开 HTTPS 解密，安装并完全信任根证书。模块只解密 app.bilibili.com、grpc.biliapi.net、api.bilibili.com，不会对所有网站启用 MITM。

iPhone / iPad：安装证书后，还需进入「设置 → 通用 → 关于本机 → 证书信任设置」，打开 PopCat 根证书的完全信任。若未完成，Bilibili 响应脚本不会运行。

「海外代理」模式下已启用模块自动生效；不要打开模块详情中的「全局模式下生效」。
